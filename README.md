# MURILO RECARGAS — site

Site estático feito em HTML e CSS, pronto para GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (por exemplo `murilo-recargas`).
2. Envie todos os arquivos desta pasta, mantendo `assets/murilo-recargas.png` dentro da pasta `assets`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde alguns minutos e abra o endereço publicado indicado na própria página Pages.

Não renomeie nem mova o `index.html`, `style.css` ou a pasta `assets`.
